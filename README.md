# Lista de compras

Carrito en el navegador: productos con precio, borrar por posición y total.

## Qué hace

- Añadir producto + precio en euros
- Listar y contar ítems
- Eliminar por índice o vaciar todo
- Calcular el total
- Guía en `guide.html`

## Cómo probarlo

Abre `index.html`. Todo ocurre en memoria (no guarda al recargar).

Demo: https://moussijoelle.github.io/lista-de-compras/

## Cómo lo construí

Array `carrito` en `app.js`, con validación de nombre/precio y un `render` que pinta la lista.

## Cómo verificarlo

Meto tres productos, borro uno por posición, miro el total y vacío el carrito.
