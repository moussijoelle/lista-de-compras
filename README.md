# Lista de compras

Carrito en el navegador: añades productos con precio, borras por posición y calculas el total.

## Qué hace

- Añadir producto + precio (€)
- Listar el carrito y contar ítems
- Eliminar por índice
- Vaciar el carrito
- Calcular el total de la compra
- Guía en `guide.html`

## Cómo probarlo

Abre `index.html` o la demo.

Demo: https://moussijoelle.github.io/lista-de-compras/

## Cómo lo construí

- HTML + JavaScript (array `carrito` en memoria)
- Lógica en `app.js` (validación, render, total)
- Sin backend ni `localStorage`

## Cómo verificarlo

Sin tests. Añado varios productos, borro uno por posición, miro el total y vacío la lista.
